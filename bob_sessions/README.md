# Bob IDE Task Session Summaries

Per the IBM TechXchange 2026 Dev Day Hackathon Guide (pages 4, 6, 17–18), this folder contains PNG screenshots of all relevant IBM Bob IDE task session consumption summaries as proof of Bob IDE usage.

### Instructions:
1. In Bob IDE chat interface, click **Tasks** to open the task history list.
2. Select a task related to the project submission to open it in the chat panel.
3. Click the **Task Header** at the top of the chat panel to reveal the Task Session Consumption Summary widget (displaying context length, tokens, cache, workspace, and API cost).
4. Take a clear PNG screenshot of the consumption summary.
5. Save the screenshot to this folder using the required naming convention:
   `kanak_waradkar_task<XX>_<short_description>_summary.png`

### Example filenames:
- `kanak_waradkar_task01_history_miner_summary.png`
- `kanak_waradkar_task02_static_validator_summary.png`
- `kanak_waradkar_task03_surgical_fixer_summary.png`
- `kanak_waradkar_task04_e2e_orchestration_summary.png`
